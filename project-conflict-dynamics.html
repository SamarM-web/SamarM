Patterns in Conflict Dynamics

A statistical test of how armed groups organize, using event-level conflict data and a physics-based fusion–fission model.

  • α ≈ 2.5exponent the model predicts
  • 2.5–3.5range of estimated exponents
  • 180-dayrolling estimation windows

The fusion–fission model predicts that when armed groups constantly merge into larger units and break apart, fatalities per event follow a power-law distribution. Working with event-level records from ACLED, I estimated the power-law exponent for each conflict period and in rolling 180-day windows, and tracked how it shifted around major turning points. Drops in the exponent lined up with periods when larger, coordinated groups became more active.

To make sure these shifts were not due to chance, I compared the real results against thousands of randomly shuffled versions of the data. I built the analysis in Python (pandas, NumPy, SciPy, statsmodels, NetworkX, Matplotlib) with Git for version control.
