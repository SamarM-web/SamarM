Río Santiago Water Quality Atlas

An end-to-end data science project on water quality in the Río Santiago, Mexico: from a database of raw monitoring records to models and an interactive atlas.

  • 87,926records
  • 13monitoring stations
  • 2009–2025years covered

What I built

  • Database. Designed and built a SQL database that brings 16 years of station records into one clean, queryable source.
  • Trend analysis. Seasonal Mann–Kendall tests at each station, with false discovery rate correction across all tests.
  • Machine learning. Benchmarked ridge regression, random forest and gradient boosting with time-based validation, so every model is tested on later data than it was trained on.
  • Atlas. Published the results as an interactive website, including a data-quality page.
